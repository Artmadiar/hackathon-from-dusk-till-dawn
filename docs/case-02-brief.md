# Кейс 02 — Agentic Economy (партнёр: Masumi)

## Формулировка (с сайта + объявление на kick-off)
> Implement an end-to-end scenario with agent discovery, financial transactions, payments, wallets and dispute resolution. Requires visible transaction outcome (sandbox or clearly labeled simulated payment acceptable).

Оси кейса: **discovery · payments · trust**.

Нужно собрать сквозной сценарий, в котором агенты **сами проводят настоящие финансовые операции**, а не только описывают их. Можно взять agent-to-agent discovery, платежи, кошельки, разбор споров — или всё сразу.

**Проблема, которую закрываем:** любая сделка между агентами всё равно заканчивается тем, что человек платит своей картой.

## Definition of Done (минимум)
- Прошла **хотя бы одна реальная транзакция**.
- Мок-платежи допустимы, только если явно помечены **`SIMULATED`**.

## Что выигрывает (критерии победы кейса)
1. **Человек не нажимает кнопки** — полностью автономный прогон.
2. **Лимиты соблюдаются** — агент не может потратить больше разрешённого (бюджет / лимит на сделку / на период).
3. **Ничто не оплачивается дважды** — идемпотентность, защита от double-spend / повторного списания при ретраях и сбоях.

Это три явных теста, которые жюри будет мысленно прогонять. Демо должно показать каждый из них явно: (а) запуск без вмешательства, (б) попытку выйти за лимит → отказ, (в) повтор/ретрай → второго списания нет.
