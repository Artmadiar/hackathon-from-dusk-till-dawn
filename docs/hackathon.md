## Критерии оценки (каждый 1–5, итог = Σ балл/5 × вес)
| # | Критерий | Вес | Что значит 3 / 5 |
|---|---|---|---|
| 1 | **Working end-to-end result** — сценарий проходит от входа до полезного выхода | **35%** | 3 = один полный core-сценарий работает; 5 = убедительно на нескольких примерах + обработаны важные failure cases |
| 2 | **Value & track relevance** — ясная проблема, значимый результат для пользователя | **25%** | |
| 3 | **Technical execution** — уместные техрешения, доказательства надёжности | 20% | |
| 4 | **Originality** — новый подход или вдумчивая комбинация известного | 10% | |
| 5 | **Validation & honest limitations** — проверили результат, честно отметили что работает / что симулировано / что не доделано | 10% | |

3 по всем = 60/100. 60% веса — «работает end-to-end» + «релевантность». Красивая архитектура без работающего сквозного прогона проигрывает.
